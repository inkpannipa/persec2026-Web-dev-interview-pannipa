# Web Developer Pre-Interview Test

คำตอบแบบทดสอบเขียนด้วย TypeScript แยก function ตามโจทย์ทั้ง 6 ข้อไว้ใน `src/answers.ts`

## วิธีรัน

```bash
npm install
npm test
```

## หมายเหตุ

- ข้อ 2 ใช้การเรียงแบบตัวอักษรและมองตัวเลขเป็นค่าตัวเลข
- ข้อ 3 ถ้าตำแหน่งที่พบคำค้นเท่ากัน จะคงลำดับเดิมของข้อมูล
- ข้อ 4 รองรับเลข Roman มาตรฐานตั้งแต่ 1 ถึง 3,999
- ข้อ 6 ถ้าค่าเริ่มต้นมีไม่ครบ 3 ตัว จะเติม `0` ให้ครบก่อนคำนวณ แต่ผลลัพธ์จะมีความยาวไม่เกินจำนวน
